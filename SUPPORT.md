# Support

## Documentation

- [Quickstart](docs/quickstart.md): start the stack and complete the first Q&A.
- [Troubleshooting](docs/troubleshooting.md): ports, model configuration, parsing,
  migrations, and common container issues.
- [Architecture](docs/architecture.md): components, ingestion, retrieval, and tenancy.
- [Operations](docs/operations.md): backups, upgrades, failure drills, metrics.
- [Releases](docs/releases.md): artifact verification, upgrade and rollback.
- [API reference](docs/api.md) and the generated
  [OpenAPI document](api/openapi/openapi.yaml).

## Questions and bugs

- Usage questions and design discussions: GitHub Discussions (when enabled) or an
  issue using the question template.
- Reproducible bugs: open a bug report with version, deployment method, logs, and
  minimal reproduction steps.
- Feature requests: describe the user problem and the acceptance criteria.

There is no guaranteed response time. This project does not currently offer
commercial support, SLAs, or hosted service.

## Security

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).

## Commercial and deployment support

For private deployments, integrations, or evaluation support, open a GitHub issue
with the `commercial` label or contact the maintainer listed in
[CODEOWNERS](.github/CODEOWNERS). Availability and terms are discussed case by case.
