## 发布前硬性检查

- [ ] README 版本号与 Release 一致（当前 `v0.2.0`）
- [ ] 全新环境 `git clone && cp .env.example .env && ./scripts/quickstart.sh` 可完成首问（不需要模型 API Key）
- [ ] 所有截图不含本机路径、租户名、密钥或内网地址
- [ ] 文章中的数字均有仓库内证据（验收脚本、报告、Release 产物）
- [ ] 对外不宣称“企业 GA”，能力边界与 SECURITY 链接可点
- [ ] ParadeDB/MinIO/Redis 许可说明只在被问到时引用 `docs/comparison.md`，不做商业分发承诺
